# PC-Check USB

Карманная утилита на Python для осмотра подержанного компьютера. Вставьте флешку, сверьте комплектующие с объявлением и выберите нужный тест в русскоязычном терминале.

## Быстрый старт

1. Скачайте архив **PC-Check-USB-0.1.zip** из раздела Releases и распакуйте папку **PC-Check** на флешку.
2. На проверяемом компьютере с Windows 10/11 x64 откройте **START.bat**. Python входит в комплект. Для проверок не требуется подключение к интернету.
3. Введите **1** и сверьте модели процессора, видеокарты, платы, планок памяти и накопителей с объявлением.
4. Запустите нужные тесты. Пункт **5** запишет результаты текущего сеанса в текстовый файл рядом с программой, в папке **reports**.

| Пункт | Что проверяет |
|---|---|
| 2 · Видеокарта | 20 секунд рисует вращающееся кольцо в окне OpenGL. Показывает активный рендерер, число кадров и среднюю частоту. Каждый кадр сверяет контрольный пиксель. Для досрочного выхода удерживайте Esc. |
| 3 · Процессор | Один поток 10 секунд вычисляет SHA-256 и сравнивает каждый результат с известным эталоном. |
| 4 · Память | Записывает четыре шаблона в 128 МиБ памяти процесса и проверяет чтение после каждого прохода. |

## Как читать результат

Для видеотеста нужен рабочий драйвер с поддержкой настольного OpenGL в режиме совместимости. На ноутбуке с двумя GPU смотрите строку «Активный рендерер». Если там встроенная графика, выберите для runtime/python.exe высокопроизводительный GPU в параметрах графики Windows и перезапустите утилиту. Замеченные на экране полосы и мигание оценивайте отдельно. Частота кадров зависит в том числе от вертикальной синхронизации.

Проверки короткие. Совпадение контрольного пикселя подтверждает чтение одного участка кадра. Тест памяти охватывает только выделенный буфер. Для накопителей отображаются модель и объём. Утилита не измеряет температуру, износ SSD и стабильность под длительной нагрузкой.

## Исходники

- check.py — меню, тесты CPU и памяти, отчёт. Для характеристик вызывает встроенный в Windows PowerShell и читает CIM.
- gpu.py — сцена OpenGL и проверка кадра через стандартный модуль ctypes.
- START.bat — запуск переносной сборки.
- runtime/ — переносимый CPython 3.13.9 x64. Лицензионные уведомления находятся в runtime/LICENSE.txt.

Для разработки можно запустить python check.py на Windows с установленным Python 3.13 x64. Сторонние Python-пакеты не требуются.
